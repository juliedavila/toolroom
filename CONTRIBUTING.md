# Contributing

## Issues are welcome

Open an issue at <https://github.com/juliedavila/toolroom/issues> for a wrong statement, a broken example, a tool that disagrees with its specification, or a question an adopter's agent could not answer from the edition. Name the design, the edition and the file.

## Pull requests are not merged

Each edition is generated from design sources that are not in this repository yet (the README's "What is not here yet" says so). A change made directly to an edition folder would be overwritten by the next release, and a released folder never changes. Describe the change in an issue instead. If it is taken up, it ships in the next edition and the changelog says so.

## Security problems

Report them privately, as [SECURITY.md](SECURITY.md) describes. Never in a public issue.
